# WaveCrux EDU Learning Packs

Ready-to-teach lab exercises for HDL/digital-design coursework, built around
the open-source-core [WaveCrux](https://wavecrux.com) waveform viewer.

This directory is the **Tier-A WaveCrux-only** catalog that ships during the
WaveCrux public-beta window. Each pack is a complete drop-in lab — HDL
source, testbench, generated waveform fixtures, a pre-saved session stub, an
expected-state file, English student handout, and English instructor notes
— plus translate filters, decoder bindings, or Stage panel configs where
applicable.

> **All packs run on Open Core.** Every feature exercised (signal browsing,
> cursor / marker navigation, translate filters, FSM Visualizer, the
> WaveCrux Stage SDK with the Tachometer + educational board widgets, plus
> the bundled protocol decoders — APB, AHB-Lite, AXI4-Lite, Wishbone,
> RISC-V, SPI / SPI Flash, UART, etc.) is part of the free open-core
> distribution. No EDU license activation is required to run the labs.

## Rebuilding fixtures

A working installation of [Icarus Verilog](https://github.com/steveicarus/iverilog)
(`iverilog` + `vvp`) is required. GTKWave's `vcd2fst` is optional — if
present, packs also produce a sibling `reference.fst`.

```bash
# Rebuild a single pack
cd packs/counter-lab && ./build.sh

# Rebuild every pack
./tools/build-all.sh
```

Each pack's `build.sh` is intentionally short and self-contained so an
instructor can read it end-to-end before assigning the lab.

## Repository move at beta launch

This catalog stages in the closed-source `wavecrux-pro` repo during pre-beta
development. At **WaveCrux beta launch** it migrates to a public repository
at `edacrux/edacrux-edu-packs` and is then consumed by `edu.edacrux.com` as
its source of truth. The CC-BY-4.0 license and the
forward-compatible manifest schema are designed to make that move a pure
copy — no schema migration, no licence flip.

## Forward-compatible manifest schema

Every pack uses `schema_version: 1`. The list-or-map shapes
(`required_tools`, `content.fixtures.sessions`,
`content.student_handouts`, …) are preserved even when only one entry is
populated. This keeps the multi-tool Tier-B/C/D catalogs that arrive at
WaveCrux beta + 8 weeks (NetCrux / LintCrux / SimCrux) a pure additive
change — no schema bump, no migration script.
